We are generating a new feature for our website.

The goal is to create a modal view that allows users to input their own SVG/PNG, brand color, and product description. On activation, the function will output an Icon Analysis and Design Score using existing functionality.

The user flow is as follows:
- Pressing Plus button on the button bar (next to search) will open a modal
- User will upload their SVG/PNG (required) add a product description (required) and specify a brand color in hex code format (optional)
- User clicks "Review My Logo"
- Information is passed to our analyze-icon function
- Icon Analysis and Design Score is displayed below the user input
